# Security

- Never commit `.env`, credentials, tokens, or database exports. Load secrets from secure runtime configuration.
- Core bearer credentials are private user data and must stay in Android secure storage. Do not log or include them in issues or screenshots.
- Local conversation caches can contain personal content. Keep device data and diagnostic captures private.
- Do not include credentials or private conversation content in public issues. Use GitHub private vulnerability reporting when enabled, or contact the maintainer privately through GitHub.
